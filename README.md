# Swill Bucket Variants

独立重写的 Fabric 1.21.1 泔水桶模组，不依赖 Brainlayers 或 NeoForge。

## 功能

- 原始泔水桶、斑驳、锈蚀、氧化及对应涂蜡变体
- 食物存储、取出、满桶食用和骨粉产出
- 漏斗输入输出、比较器输出、红石操作脉冲
- 热源加热、熔炉配方转换和烟雾粒子
- 自然氧化、蜂蜜脾涂蜡、斧头除蜡和刮氧化
- 方块转换和破坏时保留内部内容

## 环境

- Minecraft 1.21.1
- Fabric Loader 0.18.5 或更高
- Fabric API
- Java 21

## 构建

```powershell
gradle build
```

构建产物位于 `build/libs/`。

Fabric Loom 1.10.5 需要 Gradle 8.12 或更高版本；本项目已使用 Gradle 9.4.1 验证。
