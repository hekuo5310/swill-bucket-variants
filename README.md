# Swill Bucket Variants

独立重写的 Fabric 1.21.1 泔水桶模组。

## 功能

- 原始泔水桶、斑驳的泔水桶、锈蚀的泔水桶、氧化的泔水桶
- 涂蜡的泔水桶以及三种涂蜡氧化变体
- 20 层食物或原版可堆肥物品存储，支持顶层取出
- 满桶后锁定内容，可喂玩家或潜行取出骨粉
- 普通可堆肥物每 4 个折算 1 点营养，方块物品每 3 个折算 1 点营养
- 漏斗输入输出、比较器输出和内容变化红石脉冲
- 在火、灵魂火、熔岩、岩浆块或营火上加热 600 tick，按熔炼配方烹饪
- 自然氧化、蜂蜜脾涂蜡、斧头除蜡和去氧化
- 方块变体转换与破坏时保留桶内内容

## 兼容范围

本项目对齐了原泔水桶的核心存储、食用、堆肥、自动化、红石与加热行为。Brainlayers 整包的专属附魔、Farmer POI、动物吸引/繁殖、成就、香料与姜系统、专属粒子和效果不属于当前 Fabric 移植范围，因此不能宣称整个原模组绝对一比一。

## 环境

- Minecraft 1.21.1
- Fabric Loader 0.18.5 或更高版本
- Fabric API 0.116.14+1.21.1
- Java 21

## 构建

```powershell
gradle build
```

构建产物位于 `build/libs/`。本项目已使用 Gradle 9.4.1 构建验证。
